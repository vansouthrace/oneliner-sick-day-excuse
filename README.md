## Entry

> Can't come in today — I woke up fluent in a language nobody at the office speaks, and HR says I need a translator or a sick note.

## How it works

`main.ts` writes the entry to `/output/entry.txt` (validated to 1–200 characters, single line).

Run it with Node:

```sh
node main.ts
```

## Why this line

Half believable, fresh, and the twist lands at the end: waking up fluent in a
language nobody at the office speaks, then HR turns it into paperwork. It
reads like a real message someone would actually send to call in sick.
